Descripción

¿Te encanta la tinta gel? ¡Este set de lápices en formato blister es perfecto para ti!

Con punta fina y de suave trazo, ideal para una escritura precisa y cómoda.

Incluye bola de tungsteno, asegurando un flujo de tinta regulado y sin escapes.

Cono y clip de plástico, haciendo de este lápiz un producto liviano y práctico para llevar a todas partes.

Cuerpo transparente, lo que te permite ver siempre el nivel de tinta restante.

Punta de 0.7 mm con un ancho de trazo de 0.32 mm, perfecto para detalles finos.

Punta de acero, ofreciendo mayor durabilidad y resistencia.
